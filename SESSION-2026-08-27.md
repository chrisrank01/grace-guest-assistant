## ARCHITECTURE & CONTRACTS

### Widget — `public/grace-assistant.js`

Vanilla JS, no dependencies, no build step. Renders entirely inside a **shadow root** with
`:host { all: initial }`, so the host page's CSS cannot reach in and the widget cannot leak out.

#### Embed contract (three-tier route resolution)
```
data-route attribute  →  ?ga-route= query param  →  window.location.pathname
```
`normalize()` lowercases and forces leading/trailing slashes. `pickRoute()` matches exact → longest prefix
→ the literal `default` key. **`answers.json` has no `default` key**, so any page not listed renders
*nothing at all* — `build()` returns early at the "no starters" guard. That is the default-hide contract
from the corpus PLACEMENT tab, enforced in code.

Because `data-route` is optional, **one site-wide snippet works everywhere.**

#### Interaction / a11y
- **Modality-aware focus.** `lastInputWasKeyboard` tracked via `pointerdown`/`mousedown`/`touchstart`
  (capture, passive) → false, and `keydown` on Tab/Enter/Space/Arrows/Home/End → true. Both the shadow
  root and `document` are listened to. `focusFirstOption()` returns early unless keyboard. This kills the
  WebKit bug where programmatic `.focus()` paints a ring for touch users.
- Bare `:focus` is killed on **all** interactive elements including the launcher wrapper.
  `:focus-visible` = 2px orange ring (3px navy on the launcher bug).
- `:active` press states (tint + `scale(0.98)` on chips) sit **outside** the `(hover: hover)` query and
  self-clear. `-webkit-tap-highlight-color: transparent` on launcher, chips, restart, close.
- **All six `:hover` rules are gated inside `@media (hover: hover)`** — iOS sticky-hover eliminated.
- `role="dialog"` + `aria-label="Grace guest assistant"`; `role="log"` + `aria-live="polite"` on the
  transcript; `aria-expanded` on the launcher; Escape closes; focus returns to the launcher on close for
  every modality; `prefers-reduced-motion` disables transitions.
- Answers are set with `textContent`, never `innerHTML`. Links come only from the structured `links`
  array. External hosts get `target="_blank" rel="noopener noreferrer"`. A non-technical editor cannot
  introduce script through the Sheet.
- **No text input exists anywhere in the widget.** Tap-only is structural, not enforced by validation.

## STANDING RULES

1. **Exit 0 / green check is not proof.** Read the `RESULT status=` line. `debounced` exits 0 and shows green.
2. **Verify deploys twice, with cache-bust.** Cloudflare's edge served stale reads three times, twice
   producing a false "deploy failed".

   verify, I verified — several were wrong (the pinned row was never an overlay; the credential had no Drive

   the query, or `serve` returning a 301 body.

   structurally unfailable; the replacement was proven to fail before being trusted.

7. **Keys never in git.** Canary-test the ignore *before* the key exists near the repo.
8. **No terminal output pasted into chat** — operator prompts and paste-backs.
9. **The phone is the final verdict** on any visual change. Headless Chrome clamps its viewport at ~500px
   and ignores device-scale-factor for CSS viewport; use an **iframe** to render narrow, and even then it is
   Chrome, not Safari.
